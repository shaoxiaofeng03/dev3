## 这份计划怎么来的

你的起点是「Java 后端扎实、AI 与 Python 零基础、在职、每天 2 小时 + 周末 8 小时」。所以这份计划刻意做了三件事：**不重学编程**（Python 只补到能写服务）、**不铺开广度**（20 周只做两个深项目 + 一个 Java 项目）、**不留「学完再投」的幻想**（第 17 周就开始投递）。

## 六条原则

1. 先工程，后模型：把重试、超时、校验、评测、可观测当第一课，而不是最后补。
2. 两个深项目 > 五个 demo：每个项目都要有评测数据、失败案例和取舍论证。
3. 每周只改一个变量：尤其是 RAG/Agent 调优，否则永远说不清是谁的功劳。
4. Java 不丢：用 Spring AI / LangChain4j 把 AI 能力接进存量系统，这是你的差异化。
5. 边做边投：3 月中旬启动投递，用真实面试反馈驱动最后四周的补强。
