## 卡片清单（快速浏览 / 打印）

### 1. 工具粒度怎么定？太粗和太细各有什么问题？

**答**：太粗：一个工具做太多事，模型无法组合、失败难定位；太细：工具数量爆炸，选择困难、步数变多。经验：一个工具对应一个「业务动作」，参数不超过 5 个，返回结果控制在上下文可承受范围。

<small>标签：工具 · ID：w12-c1</small>

### 2. Agent 执行中工具失败了，应该怎么处理？

**答**：分层：① 可重试错误（超时、限流）自动重试；② 参数错误把错误信息回填让模型修正；③ 业务错误（无权限、数据不存在）返回明确原因并给替代方案；④ 连续失败触发熔断，降级为人工或返回部分结果。

<small>标签：可靠性 · ID：w12-c2</small>

### 3. Agent 项目怎么设计才「可演示」？

**答**：选一个 3 分钟内能跑完、结果肉眼可验证的任务；准备一条正常路径 + 一条失败恢复路径；保留 trace 面板随时能展开看步骤；预置演示数据，避免现场依赖网络和第三方服务。
