### 单变量优化

从 W3 的三类错误里挑最大的两个：加 rerank、改切分、加 query 改写。每次只改一个，复测同一批题。

记录改前/改后指标和配置；没有对比表的优化不算优化。

### 补难例

多跳、否定、时效各补几条；难例不是为了好看，是为了暴露真实短板。

### 3 分钟演示

问题 → 方案 → 数据 → 取舍；先讲「原来多少分、现在多少分、为什么」，再演示。
