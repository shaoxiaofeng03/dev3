### 权限必须下推到检索层

先取 top-k 再按权限过滤，用户可能拿到 0 条结果，还会通过「有没有结果」泄露信息。

权限、租户、时间范围都应写入 metadata，在 query 时用 filter 下推。

### 语义缓存的三个坑

阈值太难定：低了答非所问，高了等于没缓存；不同用户/租户/权限不能共用；知识更新后必须按文档版本失效。

先做精确缓存（query hash），语义缓存只对高频、低风险问题开放。

### 成本四杠杆

减少无效上下文、模型分层、缓存、减少重复计算（embedding 缓存、增量索引、批处理）。

每个杠杆都要用评测确认效果不掉。

## 常见坑

- 检索后过滤，导致越权或空结果。
- 语义缓存跨租户复用，直接泄露数据。
- 限流只限 QPS，不限 token 预算，成本照样失控。
