# 南京岗位地图与投递策略

这份计划的默认投递策略是：**南京为主场（约 6 成），上海为第二战场（约 3 成），杭州 / 苏州做补充（约 1 成）**。原因很现实——南京的 AI 应用岗位数量不如北上深，但竞争者更少、通勤与生活成本更低，而且南京的岗位结构恰好偏向 Java 栈，这对你是加分项。

> 下面的公司名单是**去处类型**的示例，不是内推名单；每年招聘情况变化很大，以当年 JD 为准。

## 一、南京的五类去处

| 类型 | 常见去处（示例） | 岗位特点 | 面试重点 | 你的匹配度 |
| --- | --- | --- | --- | --- |
| 通信 / 终端大厂研发中心 | 华为南研所、中兴、以及各家终端厂商的南京研发 | 平台大、流程正规、强度高；AI 应用岗多在内部效率工具、知识库、智能客服 | 机考（算法）+ 八股 + 项目深挖 | 中：算法是门槛，需要前 6 周把题单打完 |
| 金融科技 | 南京银行、江苏银行、华泰证券等 | 稳定、Java 为主、重合规与审计；大模型多用于客服、投研、风控辅助 | 笔试（行测 / 英语 / 计算机基础）+ 项目 + 稳定性 | 高：你的 Java 工程能力和「审计 / 权限」方案正好对口 |
| 电力 / 能源 / 工业 | 南瑞集团、国电南自、亿嘉和、埃斯顿等 | AI 落地偏视觉检测、调度、机器人；Java / C++ 混合；国企流程慢 | 项目落地能力 + 行业理解 + 稳定性 | 中高：B 端工程经验值钱，但要接受流程长 |
| AI / 软件产品公司 | 云问科技、硅基智能、焦点科技、途牛、汇通达、苏宁等 | 直接做 AI 产品，RAG / Agent 需求最集中 | 项目深度 + 评测数据 + 系统设计 | 最高：你的两个项目就是为这类岗位准备的 |
| 外包 / 驻场 / 科技子公司 | 各类软件服务商、银行科技子公司 | 门槛低、上手快，但成长性与话语权有限 | 基础八股 + 能干活 | 保底选项，尽量不作为第一选择 |

## 二、南京的三个现实

1. **岗位标题里常常不写「AI」。** 很多机会叫「知识库工程师」「智能客服研发」「大模型应用开发」「算法工程（应用方向）」「Java 开发（AI 方向）」。搜索时这些关键词都要试，别只搜 “Agent”。
2. **流程比一线慢。** 国企、银行、研究所从投递到 offer 常要 2–4 周甚至更久，所以第 17 周就要开始投，不能等到 4 月。
3. **学历与笔试是硬门槛。** 银行 / 研究所 / 部分国企有统一笔试（行测 + 英语 + 计算机基础），这部分和你的技术准备是两条线，第 16 周要单独安排 2 周刷笔试题。

## 三、投递节奏（对应计划 W17–W20）

| 时间 | 动作 | 目标 |
| --- | --- | --- |
| W16（3/8） | 简历定稿 + 开始刷银行/国企笔试题 | 简历敢投，笔试不裸考 |
| W17（3/15） | 投 30 家：南京 20 + 上海/杭州 10 | 建立管道，先拿反馈 |
| W18（3/22） | 面试 + 每场复盘；补投 20 家 | 把「被拒」拆成可改的项 |
| W19（3/29） | 面试高峰；错题与项目讲述迭代 | 同一类问题不犯第二次 |
| W20（4/5） | offer 对比与谈判 | 选对团队，而不只是选薪资 |

## 四、上海 / 杭州怎么用

- **上海**：高铁 1 小时出头，很多公司接受「当天往返面试」。适合投那些南京没有的岗位类型（大模型平台、Agent 基础设施、AI 原生创业公司）。
- **杭州**：电商与云厂商生态，RAG / Agent 岗位密度高，但竞争也更激烈；可以作为「拿到面试练手」的战场。
- 现实建议：**先用南京的机会练面试，再用上海/杭州的机会谈薪资**。反过来会让你在还没准备好时浪费掉好机会。

## 六、面试时怎么讲「为什么在南京」

被问到「为什么不去北京/上海」时，不要说「因为离家近」。可以这样组织：

> 我关注的是能不能把 AI 应用真正落到业务里。南京的金融、电力、制造业数字化需求很实在，而且团队规模通常更小、一个人能从检索做到上线，这种完整链路的经验在南京更容易拿到；同时我对上海/杭州的机会也保持开放。

这段话同时传达了三件事：你想清楚了、你要的是成长、你没有把路走窄。

## 七、需要提前确认的两件事

1. **目标公司是否卡学历 / 卡专业**：银行和研究所通常有明确要求，提前看 JD，不要浪费两周准备一场注定被卡流程的面试。
2. **是否接受外包**：如果 4 月前没拿到满意的 offer，外包可以作为过渡，但要选「能接触真实 AI 项目」的岗位，而不是纯人力外派。
