## 怎么用这一页

1. **第一次过**：按组顺序看，先在脑子里回答，再点开。答错的在笔记里记一笔。
2. **每天 10 分钟**：只看「易坑」筛选，重点扫你标过的条目；已看数量会自动记住。
3. **面试前**：点右上角「全部展开」一次性扫完，比翻笔记快。
4. **导出/打印**：点「全部展开」后直接浏览器打印，就是一份完整清单。
